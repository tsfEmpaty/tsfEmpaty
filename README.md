### 🧩 Algorithms

[**Algorithms**](https://github.com/tsfEmpaty/Algorithms): solutions to classic problems from AlgoExpert,
Grokking Algorithms, LeetCode, NeetCode and Codewars, in Python. Every solution is a self-contained folder
with a write-up and its time/space complexity. The goal is intuition for patterns, not memorized answers.
The card keeps itself up to date: the solved counters and the code come straight from the repo every day.

### 💜 Aura Dark for Logseq

[**logseq-aura-dark-theme**](https://github.com/tsfEmpaty/logseq-aura-dark-theme): a deep purple dark theme
for [Logseq](https://logseq.com), ported from the Aura Dark VS Code theme. It paints the whole UI (sidebars,
menus, command palette, pages), works with both the `--ls-*` and the newer `--lx-*` token sets, styles code
blocks as window cards and bundles Hack Nerd Font, so glyphs render without installing anything.
Install it from the Logseq Marketplace: Themes → "Aura Dark".
